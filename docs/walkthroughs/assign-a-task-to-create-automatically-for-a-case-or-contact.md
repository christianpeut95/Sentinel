# Assign a task to create automatically for a case or contact

Use Sentinel to automatically create a new task (from an existing task template) for either a case or contact record

*10 steps · Created Oct 14, 2026 · Source: demo.sentinelsurveillance.app*

---

## Step 01: Click link "Settings →"

![Step 01](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-01.webp)

## Step 02: Click link "Disease & Case Management"

![Step 02](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-02.webp)

## Step 03: Click link "Diseases"

![Step 03](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-03.webp)

## Step 04: Click edit for your selected disease

![Step 04](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-04.webp)

## Step 05: Click Tasks & Surveys

![Step 05](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-05.webp)

## Step 06: Select the relevant task you want assigned

![Step 06](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-06.webp)

## Step 07: Select your auto create options

![Step 07](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-07.webp)

## Step 08: Select if you would like the auto task creation to apply to child diseases

![Step 08](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-08.webp)

## Step 09: Click Assign Task Template

![Step 09](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-09.webp)

## Step 10: Your task template automation has been assigned

![Step 10](images/assign-a-task-to-create-automatically-for-a-case-or-contact/step-10.webp)

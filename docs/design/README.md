# Design references

This directory contains the maintained Sentinel design references and brand assets used by project contributors:

- `ui-guidelines.html` — visual design system and component guidance.
- `brand-kit.html` — logo, colour and typography reference.
- `sentinel-wordmark.png` and `sentinel-logo.svg` — maintained logo assets.

These files are repository documentation. They are deliberately kept outside `Sentinel/wwwroot` and are not published as application content.
